# 📁 Exemplos de Uso - Quality Filter PDI

Esta pasta contém exemplos práticos de como usar o sistema Quality Filter PDI.

## 🚀 Exemplos Disponíveis

### `01_uso_basico.py`
- **Propósito**: Demonstra o uso básico do sistema
- **Funcionalidades**: Análise simples de PDIs e geração de CSV
- **Ideal para**: Primeiros passos e testes rápidos

### `02_feedback_responsavel.py`
- **Propósito**: Mostra como gerar feedback personalizado para responsáveis
- **Funcionalidades**: Feedback direto e específico para cada PDI
- **Ideal para**: RH e gestores que precisam de feedback prático

### `03_motivos_concisos.py`
- **Propósito**: Demonstra a geração de motivos concisos (3 pontos principais)
- **Funcionalidades**: Motivos claros e diretos para cada avaliação
- **Ideal para**: Relatórios executivos e dashboards

### `04_explicacao_notas.py`
- **Propósito**: Mostra explicações detalhadas das notas
- **Funcionalidades**: Análise completa dos critérios de avaliação
- **Ideal para**: Análises detalhadas e auditorias

### `05_relatorio_completo.py`
- **Propósito**: Exemplo de relatório completo com todas as funcionalidades
- **Funcionalidades**: Análise completa, gráficos e exportação
- **Ideal para**: Relatórios finais e apresentações

## 📊 Arquivos de Dados

### CSVs de Entrada
- `exemplo_pdis.csv`: Arquivo de exemplo com PDIs para teste
- `exemplo_pdi.csv`: Exemplo simples para testes rápidos

### CSVs de Saída (exemplos)
- `exemplo_csv_com_feedback.csv`: Resultado com feedback personalizado
- `exemplo_saida_com_explicacao.csv`: Resultado com explicações detalhadas

## 🎯 Como Usar

1. **Escolha o exemplo** que melhor se adequa ao seu caso de uso
2. **Execute o arquivo Python** correspondente
3. **Analise os resultados** gerados
4. **Adapte o código** para suas necessidades específicas

## 💡 Dicas

- Sempre teste com o `01_uso_basico.py` primeiro
- Use os CSVs de exemplo como template para seus dados
- Consulte a documentação em `/documentation/` para mais detalhes
- Os exemplos são auto-contidos e podem ser executados independentemente

## 🔧 Requisitos

Certifique-se de ter instalado as dependências:
```bash
pip install -r ../requirements.txt
```

Para funcionalidades de IA:
```bash
pip install -r ../requirements_ai.txt
```
